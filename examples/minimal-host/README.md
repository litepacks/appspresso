# minimal-host

Official **minimal** Appspresso example — lowest friction host app.

Same as `npm create appspresso@latest my-app` (default template).

## Run (monorepo)

```bash
npm install
npm run dev
```

Uses `"appspresso": "file:../.."` — run `npm run build:lib` at repo root first.

## What it demonstrates

- `bootAppspressoHost` + `HostAppFrame`
- Single route and short `appspresso.config.ts`
- Web-first workflow in under 10 minutes

Target time: **web dev server ~8 min** after clone (excluding `npm install`).

```bash
appspresso doctor
```
