# Prerequisites

- **Node.js 20+** (Capacitor 7 requirement)
- **npm** 9+ (or compatible package manager)

Optional for native:

- **Android:** Android Studio, JDK 17+, `ANDROID_HOME` set
- **iOS (macOS):** Xcode, CocoaPods
- **Maestro** (only for this repo’s E2E): `brew install maestro`

Verify tooling:

```bash
appspresso doctor
```
