# Project layout

## Host app (your code)

| Path | Purpose |
|------|---------|
| `src/main.tsx` | `bootAppspressoHost` + `HostAppFrame` |
| `src/AppRoot.tsx` | Your router (minimal template) |
| `appspresso.config.ts` | Vite config + `app` meta (id, splash, theme) |
| `.env` | `VITE_*` client env only |

## Library (`appspresso` package)

Imported by subpath:

- `appspresso/app/*` — providers, bootstrap, mount
- `appspresso/components/ui/*` — UI primitives
- `appspresso/hooks/*` — Capacitor / state hooks
- `appspresso/services/*` — side effects (used internally; call via hooks)
- `appspresso/state/*` — Jotai `appStore` atoms

Do not import `appspresso/pages/*` in production apps — template-only (see [architecture/core-vs-template.md](../architecture/core-vs-template.md)).

## State

- **Jotai** (`appStore`) — device, network, offline, sync, bootstrap
- **TanStack Query** — server cache (optional)

## Native

- `android/`, `ios/` — created by `npx cap add`
- `capacitor.config.json` — generated by `appspresso cap:config` / `native sync`
